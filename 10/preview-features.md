# C# 10 preview features

C# 10 shipped two features as **preview** only; both became stable in C# 11 (.NET 7):

- Generic attributes: [../11/generic-attributes.md](../11/generic-attributes.md)
- Static abstract members in interfaces: [../11/generic-math.md](../11/generic-math.md)

On a `net6.0` project without `<LangVersion>preview</LangVersion>`: do not use them.
